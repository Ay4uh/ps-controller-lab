How to Check Exact Battery Health & Cycle Count

Browsers restrict low-level battery cycle count and design capacity to prevent hardware fingerprinting. To view your battery's exact cycle count, maximum factory capacity, and wear level, run the native OS command below:

Windows (Command Prompt / PowerShell)

Generates an HTML report showing Design Capacity, Full Charge Capacity, and Cycle Count:

powercfg /batteryreport /output "%USERPROFILE%\Desktop\battery_report.html"

macOS (Terminal)

Prints battery condition, cycle count, and maximum health percentage directly:

system_profiler SPPowerDataType | grep -A 10 "Health Information"

Linux (Bash)

upower -i $(upower -e | grep 'BAT')
