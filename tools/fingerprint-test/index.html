How This Test Works & Privacy Guarantee

1. Standard WebAuthn Protocol This test uses the W3C Web Authentication API (`PublicKeyCredential`). It asks your OS platform authenticator (Windows Hello, Apple Secure Enclave, Android Keystore) to confirm physical user presence.
2. Zero Biometric Data Leaves Hardware Your fingerprint image, face scan, or raw biometric templates NEVER leave the secure enclave processor of your device. The browser only receives a boolean cryptographic confirmation that a verified touch occurred.
3. Sensor Not Recognized? Ensure you have registered at least one finger in your operating system settings (Windows: Settings > Accounts > Sign-in options > Fingerprint, macOS: System Settings > Touch ID & Password).
