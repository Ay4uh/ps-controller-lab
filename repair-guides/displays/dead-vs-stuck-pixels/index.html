Dead Pixel vs. Stuck Pixel vs. Hot Pixel Guide

Before initiating a monitor RMA or laptop panel replacement, inspect the screen using solid fullscreen patterns in our Dead Pixel Test and Display Uniformity Suite.

Quick Visual Diagnosis Table

Defect TypeAppearance on White ScreenAppearance on Black ScreenUnderlying Cause & Outlook
Dead Pixel Tiny solid black dot Blends in (black) All 3 RGB TFT transistors fail to receive power/signal. Software cycling rarely fixes physical open-circuit dead pixels.
Stuck Subpixel Faint tinted dot (Red, Green, Blue, Cyan, Magenta, or Yellow) Bright colored pinpoint dot One or two subpixels are locked permanently ON. Rapid RGB color cycling can occasionally unstick jammed liquid crystal alignment.
Trapped Dust / Debris Fuzzy grey/dark speck (stays visible at slight off-angles with parallax) Dark on backlit edges Microscopic dust between diffuser layers or behind cover glass; not an electrical pixel failure.

How to Run an Accurate Screen Inspection

  1. Wipe down the screen carefully with a dry microfiber cloth so surface smudges are not mistaken for dark subpixels.
  2. Open Dead Pixel Test and enter fullscreen mode.
  3. Inspect Pure Black first in a dimly lit room to reveal stuck bright RGB pixels and edge backlight bleed.
  4. Cycle through White, Red, Green, and Blue individually—single dead subpixels only vanish completely on the two other primary colors while appearing black on their own color channel.
  5. If a stuck red, green, or blue subpixel is detected, run our Stuck Pixel Fixer Tool with rapid 60Hz color cycling directly over the defect for 10–30 minutes to unstick the liquid crystal.
  6. Also test gradient banding and refresh consistency in Display Test before signing off on a new laptop or monitor.
