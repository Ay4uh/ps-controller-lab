PS5 DualSense L2 / R2 Trigger Spring Replacement

If your PlayStation 5 DualSense L2 or R2 trigger feels completely floppy, stays partially depressed, or registers ghost inputs in the Controller Input Tester, the thin steel torsion return spring inside the trigger hinge has usually snapped.

AttributeSpecification
Compatible ControllersSony DualSense CFI-ZCT1 (BDM-010, BDM-020, BDM-030, BDM-040, BDM-050)
Tools RequiredPhillips PH00 screwdriver, plastic spudger / opening pick, fine tweezers
Replacement PartDualSense L2/R2 trigger torsion spring (verify BDM revision coil width)

1. Confirm Spring Failure vs. Potentiometer Fault

Before opening the shell, connect the DualSense over USB and open Controller Lab:

  • Snapped Spring: The analog trigger returns cleanly to 0% only when you physically pull it back out with your finger.
  • Adaptive Gear Jam / Potentiometer Issue: The trigger resists movement unevenly or fluctuates electrically while the lever stays stationary.
Note on Board Revisions: Early BDM-010 and BDM-020 triggers mount the return spring along the plastic hinge pin inside the lower trigger bucket. BDM-030 / BDM-040 / BDM-050 redesigned the adaptive trigger linkage and spring diameter—identify yours using our Board Revision Decoder before buying replacement springs.

2. Disassembly Steps

  1. Unclip the lower decorative black trim faceplate starting near the USB-C port bezel using a plastic spudger.
  2. Pop out both the L1 and R1 bumper caps straight up using a pry tool to expose the upper shell screws.
  3. Remove all 4 Phillips PH00 screws (two beneath L1/R1 and two at the bottom handle tips).
  4. Release the clips along the handle seams and lift off the rear backplate carefully without pulling the microphone ribbon.
  5. Disconnect the battery connector straight upward before servicing trigger brackets.

3. Swap the Torsion Spring & Test Travel

  1. Using fine tweezers, extract any broken steel halves from the trigger hinge barrel.
  2. Slide the replacement torsion spring onto the pivot post so the straight leg braces against the fixed housing shelf and the hooked leg engages the trigger lever pocket.
  3. Snap the L2/R2 trigger cap back onto the hinge pin and confirm crisp mechanical snapback before snapping the backplate shut.
  4. Test smooth 0.00 → 1.00 analog axis linearity and adaptive resistance inside Controller Lab.
