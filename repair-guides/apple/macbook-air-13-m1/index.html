Troubleshooting

Screen is black but laptop is on
Check display cable connection and verify panel pixels using our Display Test. If an external monitor works cleanly, the internal eDP assembly or flex cable is at fault.
Display flickers randomly
Test uniformity and backlight stability. If lines change when moving the hinge angle, the A2337 display assembly requires replacement.
Battery draining extremely fast
Check battery health in macOS System Settings → Power. If Maximum Capacity is below 80% or status reads Service Recommended, replace the A2389 battery cell pack.
Keys feeling sticky or not registering
Run our MacBook Keyboard Test to isolate unreactive switches and test for chattering before cleaning keycaps with compressed air.
